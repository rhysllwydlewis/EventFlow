# EventFlow Community — parity matrix

**Date:** 3 August 2026
**Reference behaviour source:** see the methodology section of
[`eventflow-community-hitched-audit.md`](./eventflow-community-hitched-audit.md).
Reference-side behaviour in this matrix is **asserted from the product category
and the brief, not from a live inspection made during this session**, because
the execution environment could not reach the reference site. The EventFlow
column and the Evidence column are verifiable against this repository.

**Parity verdicts:** `Exact` — same information architecture and workflow.
`Adapted` — same user goal, EventFlow's own design system and data.
`Improved` — same user goal, materially better behaviour, reason stated.
`Omitted` — deliberately not reproduced, reason stated.

## Coverage statement

Every page type, module and interaction the brief enumerates has an entry above.
Three are deliberately omitted with a stated reason (users-online counter,
video strip until real video exists, unstructured for-sale board). Nothing else
in the brief's list is missing.

**The Evidence column cites EventFlow-side proof only.** Reference-side evidence
is the outstanding human task described in the audit's methodology section.
