Event Contracts, Deposits and Cancellation Terms Guide

Before money changes hands, make sure the booking terms match what you think you are buying.

📚 9 min read • Updated June 2026

In this guide
  1. Get the basics in writing
  2. Cancellation and postponement
  3. Managing changes
  4. When to pause before paying

Get the basics in writing

A good booking confirmation should set out the supplier name, event date, location, arrival time, service duration, package details, price, deposit, balance date and what happens if either side needs to change the booking.

Do not rely on a quick message thread for important terms. Ask for a proper written confirmation or contract before paying a deposit.

Read cancellation and postponement wording

Check what happens if you cancel, if the supplier cancels, if the venue changes, or if the event needs to move date. Pay attention to non-refundable deposits, balance due dates and whether postponement is treated differently from cancellation.

Manage changes properly

If the scope changes, get the change confirmed in writing. Guest numbers, extra hours, travel, access, setup time and equipment changes can all affect cost. Keep the latest agreed version in one place.

Know when to pause before paying

Pause if the supplier will not provide written terms, asks for unusual payment methods, avoids basic questions, or pressures you to pay immediately without a clear scope. A professional supplier should be comfortable giving clear booking information.
